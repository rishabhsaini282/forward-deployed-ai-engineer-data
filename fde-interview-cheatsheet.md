# Forward-Deployed AI Engineer (FDE) Case Study Rubric

FDE interview panels assess system integration architecture, real-time context management, and technical communication choices under heavy ambiguity[cite: 6]. Use this reference sheet to prepare for active decomposition loops.

## 1. The Active Discovery Protocol
*When presented with a highly vague customer statement, you must immediately validate the operating constraints by asking three unprompted questions before talking about code or APIs:*[cite: 6]

1.  **Data Isolation Parameters:** "Do we possess direct architectural permission to configure a secure, live API proxy layer over the current stack, or are we structurally bound to handle raw, offline batch exports?"[cite: 6]
2.  **Latency Constraints:** "What is the absolute end-to-end latency threshold permitted for this query generation before it breaks core business operations?"[cite: 6]
3.  **Harness Verification:** "What historical manual logs or validated outputs exist to serve as a ground-truth dataset for automated regression metrics tracking?"[cite: 6]
