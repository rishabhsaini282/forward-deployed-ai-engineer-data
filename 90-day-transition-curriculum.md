# The 90-Day Applied AI Transition Curriculum

A complete weekly learning guide to bridge the transition gap from traditional application development or data science tracks into production-tier AI delivery engineering[cite: 11].

## Phase 1: Weeks 1–4: Production Foundations & Enterprise Infra
*   [ ] **Harden the Systems Layer:** Optimize multi-layered data transforms across complex Python environments; achieve clean execution writing and debugging 200-line SQL scripts completely without visual tooling assists[cite: 11].
*   [ ] **Systems Language Literacy:** Achieve structural comfort tracking and tracing processing loops inside Go or Rust configurations[cite: 7, 11].
*   [ ] **Cloud Access Management:** Programmatically construct secure VPC peering links, cross-account AWS IAM role limits, and secret managers behind local network firewalls[cite: 6, 11].

## Phase 2: Weeks 5–8: Applied Composition & Validation Harnesses
*   [ ] **Advanced Retrieval Mechanics:** Build custom contextual grounding pipelines combining dense semantic vector lookups with sparse hybrid indexing topologies[cite: 4, 6].
*   [ ] **Automated Evaluation Suites:** Construct programmatically driven "LLM-as-a-Judge" grading pipelines using LangSmith or DeepEval to trace semantic drifting[cite: 2, 4, 11].
*   [ ] **Threat Matrix Alignment:** Code automated sanitation rules to validate system message bounds against prompt injection following the OWASP LLM Top 10 vectors[cite: 2, 3, 11].

## Phase 3: Weeks 9–12: Legacy Simulation & Capstone Deployment
*   [ ] **Legacy Infrastructure Emulation:** Design translation proxy adapters to ingest, clean, and map raw, highly fragmented ERP legacy exports into clean schemas[cite: 7, 11].
*   [ ] **Functional Capstone Project:** Ship a working retrieval pipeline linked to a live public API, wired into an active CI/CD pipeline that automatically fires an evaluation suite pass on every individual commit[cite: 11].
*   [ ] **System Decomposition Documentation:** Map out all architectural tradeoffs, security safeguards, and scoped exclusions in a clear product documentation file in the repository root[cite: 7, 11].
